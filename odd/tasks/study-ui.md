# Study UI — redesign, 3D-ready layout, study history, replay and re-explain

Objective: a much better designed UI (via ai-frontend-guide-kit), a layout ready for a 3D character in the center and a study panel on the right, replay/re-explain actions, and a flexibility plan for revisiting past material.
Branch: `feat/study-ui`, stacked on `feat/voice-ux` (unpushed) · Delivery: ask-on-risk · Test runners: frontend `npm test` and `npm run build` in `frontend/`; backend `uv run pytest -m "not integration"`.

## Specs

- **S1 — Design kit installed and used.** User (L1): "Quiero que instales esta herramienta y mejores mucho el diseño." Kit `https://github.com/urben88/ai-frontend-guide-kit.git` v1.3.0 installed at the repo root (`ai-frontend-guide-kit/`, `ai-frontend-output/`, `.agents/skills`, `.claude/skills`, `.mcp.json` with Playwright + Excalidraw, `skills-lock.json`, `AGENTS.md`). The redesign follows its workflow (skill `ai-frontend-guide`: experience direction → composition from the catalog → polish), with the user answering its direction questions.
- **S2 — 3D-ready layout.** User (L1): "lo dejes preparado porque voy a crear un consistente 3D que esté en el medio y a la derecha tenga, por ejemplo, el historial de palabras y cosas que estoy estudiando." Three areas: conversation; a center stage slot for a future 3D character (placeholder component with a clear mount point and props for state: idle / listening / thinking / speaking, so the 3D model can react later); a right panel with the study history. No 3D library is added now.
- **S3 — Word click: listen first, explain on demand, split in tabs.** User (L1): "que a darle una palabra, pues vuelva a escucharla a no ser que yo quiera una explicación." User choice (L2): "Escuchar + explicación por pestañas" — "Clic = la oye. Botón «Explicar» genera todo de una vez y lo muestra dividido en pestañas (Traducción / Gramática / Ejemplos)." Clicking a word or selected phrase plays its pronunciation (TTS); an "Explain" action generates the explanation once and shows it in tabs: Translation / Grammar / Examples (explanations in Spanish, examples in English, as decided in phase 3).
- **S4 — Replay and re-explain.** User (L1): "Quiero también tener posibilidades de que lo vuelva a explicar, lo vuelva a leer, que vuelva a hablar para escuchar la pronunciación". Per tutor message: "Read again" (replay its audio), "Explain again" (new explanation, optionally simpler). Per explanation: "Explain again". Per word/phrase: replay pronunciation (normal and slow if the TTS speed allows it).
- **S5 — Study history.** Every word/phrase the user listens to or explains is saved (persisted in the SQLite store) with its explanation and the sentence it came from; the right panel lists it, and from each item the user can replay, re-explain, or jump to the original message.
- **S6 — Flexibility plan (document only).** User (L1): "Quiero que generes un plan de flexibilidad al final para darle diferentes usos y poder volver a explicar cosas del pasado o volver a leer las frases, retomar esa parte, etc." A short doc `docs/flexibility-plan.md` with future uses (review past sessions, resume a conversation from a point, re-read phrases, spaced review of studied words, modes such as free talk / guided practice / review), each with what exists today and the next step. Written at the end.
- **S7 — Tests and docs.** Tests for the new API endpoints and store tables (fakes), for the word click → listen / explain-in-tabs flow, replay/re-explain actions, and the study panel. README updated.
