# Study sessions — role sessions, phrase analysis, history management, configurable answers, voice ball

Objective: clearer study experience: role-based sessions, sentence analysis popup, deletable history and words, configurable answer length with controlled LangGraph context, and nicer controls.
Branch: `feat/assistant-polish` (same branch, after assistant-polish T1/T2) · Delivery: ask-on-risk · Test runners: frontend `npm test` and `npm run build` in `frontend/`; backend `uv run pytest -m "not integration"`.

## Specs

- **S1 — Voice ball.** User (L1): "El botón de para el que estoy hablando y pausarlo o mutearme, quiero que sea un círculo, una bola que tenga una animación así chula y bonita." The talk / pause / mute control becomes a circular orb with a nice animation that reflects the state (idle, listening with mic level, thinking, speaking, muted); respects prefers-reduced-motion; keyboard and screen-reader accessible.
- **S2 — Role sessions.** User (L1): "en la parte de study, quiero tenerlo más claro, es decir, quiero tener como sesiones con roles donde pueda escribir el rol del tema que quiero aprender." When creating a session the user can write a free-text role/topic (e.g. "waiter at a restaurant", "job interview"); it is stored with the session, shown in the session list, and used by the tutor for that session.
- **S3 — Icon buttons on messages.** User (L1): "en el tema de hablar, los botones de volver a leer la frase que tengan en iconos, que sean más diferenciables". Read again / Explain again / Explain simpler / Analyze become distinct icon buttons with accessible labels and tooltips.
- **S4 — Delete history and words.** User (L1): "además de poder borrar historial, borrar palabras en concreto". Delete a whole session history (with confirmation) and delete individual study items.
- **S5 — Sentence analysis popup.** User (L1): "poder analizar una frase, es decir, la frase que me ha contestado, que poder analizarla como si fuese una estructura, es decir, si me hubiera un pop-up de la frase, puedo saber las traducciones de cada palabra y además explicación de la palabra y algún tiempo verbal y más información sobre ella." An "Analyze" action on a tutor message opens a popup with the sentence structure: each word/chunk with its translation, explanation, part of speech, verb tense when it applies, and extra info; explanations in Spanish (as decided in phase 3).
- **S6 — Configurable answer length.** User (L1): "quiero que las respuestas del asistente puedan ser más largas y todo esto configurable obviamente. Es decir, puede configurar que las respuestas sean más largas, más cortas, etc." Settings with answer length (e.g. short / medium / long), persisted, applied to the tutor prompt and token limit.
- **S7 — Context window control.** User (L1): "Para todo esto ten un buen control de la ventana de contexto que estás gestionando con el LandGrab." In the LangGraph flow, bound the context sent to the LLM (role + recent turns within a token budget, older turns summarized or trimmed), so longer answers and long sessions don't overflow the model context; budget configurable.
- **S8 — Tests and docs.** Tests for each rule (backend fakes, frontend behavior), README updated.
