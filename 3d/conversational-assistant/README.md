# Conversational assistant (3D)

A stylized, textured 3D bust of the English tutor. It blinks, talks (wide mouth), changes expression, moves its head and gestures with both rigged arms. Every change eases back to idle.

## Gestures per state

Each expression carries a body pose (both arms), continuous motion and, where it fits, automatic gestures picked at random:

| State / expression | Body |
|---|---|
| idle (`neutral`) | relaxed arms, breathing sway |
| `listening` | slight lean, nods, left hand open at the waist, occasional `nod` / `listen_hand` |
| `thinking` | right hand to the chin (finger tapping), left arm across the body, head tilt |
| `speaking` | hands raised; random `explain`, `explain_left`, `open_both`, `beat`, `beat_left`, `point_soft` every 0.25-1.1 s |
| `happy` | open arms, bounce, occasional `open_both` |
| `surprised` | hands up, lean back |

One-shot gestures stay available through `gesture(name)`: `wave`, `point`, `explain`, `listen`, `idea` and the ones above. In config a gesture can use `like` (reuse another) and `mirror` (`left` / `both`), so left-arm versions need no extra numbers. Expressions accept `pose`, `oscillate`, `gestures`, `gestureEvery`. `lipSync` (`gain`, `audioGain`, `floor`) sets how wide the mouth opens. Reduced motion lowers all of it.

Model: GLB 1.35 MB (was 0.90 MB), 27 216 triangles, 21 bones, 20 morphs, 7 small JPEG textures (skin, face blush map, shirt/collar/placket weave, two hair tones; 256-512 px) generated by `build_model.py`. The camera frames head to waist so the hands show.

## Folder

```text
assets/models/        conversational-assistant.glb (runtime) + .blend (source)
assets/reference-images/  the sheet and background used as reference
config/element.config.json  camera, expressions, gestures, smoothing, states
src/                  index.ts (entry), controls.ts (animation), loader.ts, types.ts, react.tsx
examples/standalone.html  demo page with buttons for every expression and gesture
tools/                build_model.py (Blender generator), validate_model.py
validation/screenshots/   evidence for the report
dist/                 compiled JS for the demo (generated)
```

## Quick try (no install)

Serve this folder with any static server, then open `examples/standalone.html`. For example, from this folder:

```bash
npx serve .   # or: python -m http.server
```

The demo loads three.js from a pinned CDN, only for the demo.

## Rebuild

```bash
# Model (Blender 5.2+)
blender -b --factory-startup --python tools/build_model.py -- --out assets/models/conversational-assistant.glb --blend assets/models/conversational-assistant.blend
blender -b --factory-startup --python tools/validate_model.py -- assets/models/conversational-assistant.glb

# Demo JS (uses the frontend's TypeScript)
../../frontend/node_modules/.bin/tsc -p tsconfig.json --noCheck
```

## API

```ts
const a = createConversationalAssistant({ container, config, modelUrl });
await a.ready;
a.setState("listening");            // idle | listening | thinking | speaking
a.setExpression("happy");
await a.gesture("wave");
await a.speak({ audio });           // or { text } / { durationMs } / nothing
a.stopSpeaking();
a.dispose();
```
